# Dashboard Metric Calculation Windows & Aggregate Guidelines

This document provides maintainers, frontend developers, and data engineers with authoritative rules for calculating, sampling, and rendering all aggregate metrics displayed across the NeuroWealth frontend dashboard.

---

## 1. Overview & Core Principles

To ensure users, auditors, and maintainers interpret dashboard figures consistently:
- **Timestamp Standard**: All backend services, Soroban RPC responses, and database records use **ISO-8601 UTC** (`YYYY-MM-DDTHH:mm:ss.sssZ`). Any display-layer formatting into local browser time must be explicit and non-destructive.
- **Monetary Units**: On-chain values are signed 128-bit integers (`i128`) with 7 decimal places (`1 USDC = 10,000,000` base units). Off-chain display formatting converts raw integers without intermediate floating-point precision loss.
- **Missing-Data Behavior**: Missing, delayed, or disconnected data states must never be masked with fabricated non-zero defaults. Fallbacks must use explicit neutral values, skeleton states, or offline badges.

## 2. Metric Specifications

### 2.1 Total Portfolio Value / Asset Balance
- **Components**: `BalanceCard`, `PortfolioDashboard`, `AssetOverview`
- **Sample Window**: Instantaneous snapshot of the latest confirmed ledger sequence. Reflects the real-time share balance converted to underlying USDC assets:
  $$\text{assets} = \lfloor \frac{\text{user\_shares} \times \text{TotalAssets}}{\text{TotalShares}} \rfloor$$
- **Timestamp Convention**: Consensus close timestamp (`ledgerClosedAt`) of the evaluated ledger sequence in ISO-8601 UTC.
- **Missing-Data Rules**:
  - **Disconnected Wallet**: Displays `$0.00` or a prompt to connect wallet.
  - **RPC Failure / Timeout**: Retains the last confirmed cached value with a visual "stale/offline" indicator badge. Does not render an estimated balance.
  - **Zero Shares**: Explicitly displays `$0.00 USDC`.

---

### 2.2 Accrued Earnings / Yield (`today`, `week`, `month`)
- **Components**: `EarningsCard`, `EarningsHistoryChart`
- **Sample Window**:
  - **`today`**: Rolling 24-hour window from current UTC time ($T - 24\text{ hours}$ to $T$), or from current calendar UTC midnight ($00:00:00\text{ UTC}$ to $T$).
  - **`week`**: Rolling 7-day window ($T - 7 \times 24\text{ hours}$ to $T$).
  - **`month`**: Rolling 30-day window ($T - 30 \times 24\text{ hours}$ to $T$).
- **Timestamp Convention**: Transaction confirmation / ledger close timestamp recorded in ISO-8601 UTC for each attributed yield event.
- **Missing-Data Rules**:
  - **No Activity in Window**: Displays `$0.00` (neutral profit state; never negative unless an authorized loss was reported on-chain).
  - **Intermittent Missing Days**: In historical charts, days with zero yield are explicitly plotted with `$0.00` delta rather than omitted, preserving linear timescale geometry.
  - **NaN / Null Values**: Filtered out and treated as zero.

---

### 2.3 Annual Percentage Yield (APY)
- **Components**: `APYDisplay`, `StrategySelector`
- **Sample Window**: Rolling 1-hour observation window generated by the background agent daemon's evaluation loop (`agent/src/yieldCheckJob.ts`).
- **Timestamp Convention**: ISO-8601 UTC timestamp of the most recent agent APY observation (`last_updated`).
- **Missing-Data Rules**:
  - **Observation Stale (> 2 hours)**: Displays an "Observation Delayed" warning badge alongside the last confirmed rate.
  - **Service Offline / Unreachable**: Renders an offline Wi-Fi badge and preserves the last known valid APY.
  - **Unconfigured Protocol**: Displays baseline `0.00%` APY until a lending pool or DEX pool is configured and evaluated.

---

### 2.4 Vault Exchange Rate (Assets per Share)
- **Components**: `ShareRateCard`, `ExchangeRateChart`
- **Sample Window**: Real-time on-chain state read from `get_exchange_rate()`:
  $$\text{exchange\_rate} = \frac{\text{TotalAssets} \times 10,000,000}{\text{TotalShares}}$$
- **Timestamp Convention**: Ledger close timestamp of the query block in ISO-8601 UTC.
- **Missing-Data Rules**:
  - **Bootstrap Phase (`TotalShares == 0`)**: Defaults strictly to parity `1.0000000` (1:1).
  - **Simulation Failure**: Freezes at the last successfully verified rate and logs an error to monitoring.

---

### 2.5 Asset Allocation Breakdown (Idle vs. Deployed USDC)
- **Components**: `AssetOverview`
- **Sample Window**: Instantaneous snapshot read via `get_asset_breakdown()`, returning `(idle_assets, deployed_assets)` atomically in a single RPC invocation.
- **Timestamp Convention**: Ledger close timestamp of the query block in ISO-8601 UTC.
- **Missing-Data Rules**:
  - **No Active Deployment (`CurrentProtocol == "none"`)**: Deployed assets evaluate strictly to `0`; idle assets equal the contract token balance.
  - **Cross-Contract Call Failure**: If deployed pool balance reads fail, the component presents an error banner rather than displaying `0` as real liquidity.

---

### 2.6 Transaction History Aggregates
- **Components**: `TransactionHistory`, `TransactionTable`
- **Sample Window**: User-selectable historical time horizons:
  - `24h`: Transactions within the past 24 hours.
  - `7d`: Transactions within the past 7 days.
  - `30d`: Transactions within the past 30 days.
  - `1y`: Transactions within the past 365 days.
  - `all`: All recorded transactions since contract inception.
- **Timestamp Convention**: ISO-8601 UTC transaction creation timestamp from ledger records. Display layer formats this into the user's localized date/time.
- **Missing-Data Rules**:
  - **Empty Records**: Shows an accessible "No transactions found in this period" empty state card.
  - **Pending / In-Flight**: Marked with a `Pending` badge until Horizon or Soroban RPC confirms inclusion; if rejected, displays the terminal failure reason.

## 3. Summary Reference Table

| Aggregate Metric | Display Component | Sample Window | Timestamp Convention | Missing-Data Rule |
|---|---|---|---|---|
| **Portfolio Value** | `BalanceCard` | Instantaneous (latest ledger) | UTC ISO-8601 (`ledgerClosedAt`) | Show `$0.00` if disconnected; freeze last known on RPC failure |
| **Today's Earnings** | `EarningsCard` | Rolling 24h / UTC calendar day | UTC ISO-8601 (event confirmed) | Default to `$0.00`; clamp nulls to zero |
| **Weekly Earnings** | `EarningsCard` | Rolling 7 days (168h) | UTC ISO-8601 (event confirmed) | Fill inactive days with `$0.00` |
| **Monthly Earnings** | `EarningsCard` | Rolling 30 days (720h) | UTC ISO-8601 (event confirmed) | Fill inactive days with `$0.00` |
| **Current APY** | `APYDisplay` | Rolling 1 hour (agent cycle) | UTC ISO-8601 (agent observation) | Show "Stale" if >2h; render offline badge on network error |
| **Exchange Rate** | `ShareRateCard` | Instantaneous (latest ledger) | UTC ISO-8601 (`ledgerClosedAt`) | Default to `1.0000000` when shares = 0 |
| **Asset Breakdown** | `AssetOverview` | Instantaneous (atomic read) | UTC ISO-8601 (`ledgerClosedAt`) | Default deployed to `0` when protocol is none |
| **Tx History** | `TransactionTable` | 24h / 7d / 30d / 1y / all | UTC ISO-8601 (ledger inclusion) | Render empty state; mark pending transactions |
